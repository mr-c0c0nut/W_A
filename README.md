## `> What is W.A?`

**W.A** is a tiny open-source security toolkit written entirely in Python.

No framework.

No installer.

No complicated setup.

No huge folder containing hundreds of files.

Just:

```text
WA.py
README.md
```

The project is designed around one simple idea:

> **You don't need a specific operating system to learn security.**

---

## `> The story`

There was a student.

He was learning cybersecurity in class.

Everyone was using **Kali Linux**.

He decided to use **Windows** instead.

The teacher wasn't exactly impressed.

So he got kicked out of the class.

Instead of changing his operating system, he decided to build his own security toolkit.

And that became:

```text
W.A
```

The point isn't that Windows is universally better than Linux.

The point is much simpler:

```text
             ┌─────────────────────┐
             │      OPERATING       │
             │       SYSTEM         │
             └──────────┬──────────┘
                        │
                        ▼
                ┌───────────────┐
                │     USER      │
                │               │
                │  Knowledge    │
                │  Skill        │
                │  Experience   │
                └───────────────┘
```

**The operating system is a tool.
The person using it is what matters.**

# `> Usage`

There are **two simple ways** to run W.A.

## Method 1 — Clone and run

Open **CMD**:

```cmd
git clone https://github.com/YOUR-USERNAME/WA.py.git
cd WA.py
python WA.py
```

Or:

```cmd
py WA.py
```

That's it.

---

## Method 2 — Python IDLE

If you already have **Python 3.12.6** installed:

1. Open **IDLE (Python 3.12.6)**.
2. Click **File → New File**.
3. Open `WA.py`.
4. Copy the source code.
5. Paste it into the new file.
6. Press **F5**.
7. W.A starts.

```text
        +----------------------+
        | Python 3.12.6 IDLE  |
        +----------+-----------+
                   |
                   | F5
                   v
        +----------------------+
        |        W.A           |
        | Windows Security     |
        |      Toolkit         |
        +----------------------+
```

No complicated installation process.

**Copy → Paste → F5.**
